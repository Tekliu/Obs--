## RAM 随机存取存储器
- 随机存取 = 想读哪颗字节直接读，不用像磁带那样从头快进到指定位置，也不用像硬盘那样寻道。CPU 给个地址，RAM 立马返回数据，"随机"指的是访问任意位置速度都一样，不是"随便存"的意思。
-  对应概念是"顺序存取"（磁带）和"直接存取"（硬盘，介于两者之间）。 关键特性：快，但断电就空
- 关键特性：快，但断电就空 
- 速度比 SSD/硬盘快几个数量级，是 CPU 的"工作台" 
- 易失性——关机数据全没，所以叫"临时记忆"
- 你现在打开的微信、浏览器标签页，都住在 RAM 里
RAM 的两大分支

|  类型  | 全称  |         特点         |       用途       |
| :--: | :-: | :----------------: | :------------: |
| SRAM | 静态  |  RAM 快、贵、占地大、不用刷新  | 内部缓存（L1/L2/L3） |
| DRAM | 动态  | RAM 慢一点、便宜、高密度、要刷新 |    你插的那条内存条    |
