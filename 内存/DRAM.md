## DRAM动态随机存取存储器
1. CPU 干活时正在用的数据，临时搁在 DRAM 里——离 CPU 近、读得快，但断电数据就没了（易失性），所以它只是"暂存"，不是长期存储（那是硬盘/SSD 的活）。
 2. 每一比特靠**一个电容 + 一个晶体管**存电荷，电荷多了是 1、少了是 0。但电容会漏电，得定期"刷新"充电才能保住数据，这种要不停刷新的特性就叫**动态** ——对应的 SRAM（静态）就不用刷，但成本高、占地方，一般只做 CPU 缓存。
3. 电脑里那条内存条，基本都是 DRAM，目前主流是 DDR4 / DDR5（DDR = Double Data Rate，双倍速率，就是同频下传输更快的升级版）
