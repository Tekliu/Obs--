#南北桥是什么

早期 x86 主板（≈1990s–2008）是两颗芯片分工，按"快慢 + 在主板上位置"命名：

        CPU
         ↓ FSB（前端总线）
      ┌─北桥(MCH)─┐
      │ 内存控制器  │←→ 内存(DRAM)
      │ AGP/早期PCIe│←→ 显卡
      └───┛   ├───┐
          PCI总线   │
                   ↓
               ┌─南桥(ICH)─┐
               │ USB/SATA   │←→ 键鼠/硬盘/光驱
               │ 音频/网卡   │←→ 声卡/网卡
               │ BIOS/LPC   │←→ 固件/CMOS
               └────────────┘

- 北桥（Northbridge）：**靠 CPU 近**（主板"北"上半区），**管快的** —— **CPU ↔ 内存、CPU ↔ 显卡，用 FSB（Front Side Bus）跟 CPU 对话**
- 南桥（Southbridge）：靠主板"南"下半区，**管慢的杂活**——**USB、SATA、音频、BIOS、PCI 插槽，通过 PCI 总线连北桥**
为什么后来北桥没了

两个关键变动：

1. **内存控制器**搬进 **CPU**（AMD K8 2003 率先，Intel Nehalem 2008 跟进）→ 北桥失去最大一块活
2. **PCIe Root**也进 CPU → 显卡也不用挂北桥了

北桥被掏空，剩下南桥那点活 Intel 改名叫 PCH、AMD 叫 FCH，从此"南北桥"这词退出历史，变成"CPU + PCH"单芯片配角结构。

一句话：北桥 = 被 CPU 吃掉的那个，南桥 = 改名续命成 PCH 的那个。
