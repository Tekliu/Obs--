#硬盘
主要分为**机械硬盘**(**HHD**)和**固态硬盘**(**SSD**)[[硬盘(拓)]]，SATA接口就是用来连接是用来连接硬盘的，M2接口，新一代的接口标准，读写性能更快，用来连接这种 **体积更小的固态硬盘** ，**主板也有自己的芯片组**是CPU与周围设备沟通的桥梁，几乎决定着主板的全部性功能，和CPU一样，也需要一个散热器进行散
主板上还有一个**4p接口和24p**接口，4p接口不一定是四个口，有可能是8个，**4p接口主要为CPU进行供电**，**主板供电主要利用的是24匹接口**，然后有一个位置是有**BIOS电池**，然后一般用的就是cr2032(**BIOS是用于各种硬件设备的初始化和检测**)，在主板的侧面有很多的接口，**鼠标和键盘的接口是圆孔的，需要接入到Ps-2口,紫色的用于连接键盘，绿色的用于连接鼠标**
**绿色的插孔代表立体声音输出， 是用来连接耳机和音箱的，粉色的插孔一般用于连接麦克风，蓝色的插口一般是音频输入**[[显卡(GPU)]]
**梯形的叫做VGA接口**([[视频输出接口]])**HDMI**接口二者是用来连接显示器的，在主板上还有一个叫做pcie的插槽主要用于安装不同类型的扩展卡比如独立声卡和独立显卡，主板其实就是一个大号的印刷电路板，电路板上安装了各种微芯片和接口， 电路板的主要制造材料为铜板，为了绝缘和支撑还需要一块玻璃纤维材料，将两者压制在一起接着将铜板放入钻孔机进行钻孔，钻孔前需要先在铜板上覆盖一层保护铝板，然后在铜板的四个角落的位置打上四个定位孔与此同时，设计工程师会利用计算机辅助软件设计出电路板的电路图形然后存入U盘之中，Gerber是用来描述电路板线路图像钻孔的文件格式合集，将U盘插入到钻孔机上，机器会根据设计的电路图形，在电路板钻出符合设计要求的孔洞，然后对钻好孔洞的电路板进行清洁，以避免留下钻孔时的残留物，然后开始雕刻电路板上的铜迹线，首先需要在电路板上覆盖一层干膜，然后根据设计师设计的电路图，打印出光掩膜，并将光掩膜覆盖到铜板上，及时将电路板放入uv机中

裸 PCB 本身只是一块板，主板之所以是主板，是因为这块 PCB 上焊了让电脑能开机的最低配置：

- CPU 插座（LGA1700 / AM5 这种，显卡 PCB 上没有）
- 内存插槽（DDR5 四根或两根）
- 芯片组（Intel Z890 / AMD X870 这种"南桥"，负责 IO 调度，显卡 PCB 上对应的是"GPU 自己管自己"）
- PCIe 插槽（插显卡、SSD、采集卡的地方，就是你 5090 插的那个）
- M.2 接口（NVMe SSD）
- SATA / USB 3.x 主控 + 后排 IO 挡板
- BIOS/UEFI 芯片（开机第一句"嘀"就是从这儿来的）
- 供电区（VRM）：给 CPU 喂电的 DrMOS + 电感，高端主板（如 ROG Maximus）这套比中端主板还贵
