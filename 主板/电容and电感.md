电容和电感都是"储能元件"，但一个存电场、一个存磁场，稳压的维度也不一样。
⚡ 一句话直觉
- 电容：两块金属隔个绝缘，**存电场** → 特性是"**电压不能突变**"（想变？得先充/放电，需要时间）→ **用来稳压、滤纹波、隔直通交**
- 电感：线圈绕一坨，**存磁场** → 特性是"**电流不能突变**"（想变？得先建/消磁，需要时间）→ 用来**稳电流、滤高频、Buck 斩波**
🔌 VRM 的 Buck 电路里他俩怎么搭档

VRM 一相最简模型：

ATX +12V
  → 输入电容 Cin（胖电解，µF 级）
  → 上管开：+12V 灌电感 L → 电流线性爬，L 存磁
  → 上管关/下管开：L 放磁 → 电流继续往下流（靠下管回路）→ 输出电压 Vcore
  → 输出电容 Cout（MLCC 群，µF 级）×N → 把斩出来的三角波滤成直流

分工：

元件 在 Buck 里干啥 VRM 实物
输入电容 Cin 吃 ATX 12V 进口纹波，给上下管切换时供瞬时电流 ATX 24pin 旁胖电解
电感 L 斩波主角——上管开时储能、关时续流，把"+12V 方波"变成"三角电流" 每相旁边方块 
"R22" 那种
输出电容 Cout 把电感吐的三角电流滤成稳 Vcore 直流，扛负载突变 CPU 插座旁 MLCC 群（小米粒贴片）

所以电感决定"电流怎么流"，电容决定"电压稳不稳"——缺一个这 Buck 都转不成。

📊 参数/单位/特性对照

 电容 C 电感 L
储能形式 电场（两块极板夹介质） 磁场（线圈绕磁芯）
单位 F（法拉），板级用 µF/nF/pF H（亨利），板级用 µH/nH
阻抗 vs 频率 Xc = 1/(2πfC)，频率↑阻抗↓ → 滤高频好 Xl = 2πfL，频率↑阻抗↑ → 滤高频？不对，电感是阻高频通低频？等下纠正：电感对高频阻抗大，所以高频噪声电感不让过——但 Buck 里电感不是用来"滤"的，是用来"续流"的，滤波靠电容。修正：电感特性是"通低频阻高频"，但 Buck 里主业是续流不是滤波
"不能突变"的那个 电压不能突变 电流不能突变
VRM 里主业 稳压、滤纹波、去耦 斩波续流、稳电流
板级实物 电解（胖）、MLCC（小米粒）、钽 功率电感（方块）、磁珠（小粒，属电感变种但专用于滤 EMI）

💡 一个易混点：磁珠（ferrite bead） 也算电感家族，但 Q 值很低、专门吃 EMI 噪声（高频阻抗陡），不用来做 Buck 储能——VRM 输入口常见"大电感(R22) + 磁珠 + 电解"三件套，分工不同。
🛠 一个直觉实验

- 电容想象成"小水库"：水位（电压）不能瞬间涨跌，得靠进水/放水慢慢变 → 所以并路上能"托住电压"
- 电感想象成"飞轮"：转起来（电流）不能瞬间停，外力撤了还靠惯性转 → 所以串路上能"托住电流"

Buck 里：上管关的瞬间，如果没电感，电流直接断 → Vcore 塌；有电感续流，电流还能靠着 L 放磁继续流 → 这就是"电流不能突变"的硬件落点。
