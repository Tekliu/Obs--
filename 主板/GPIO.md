## GPIO = General-Purpose Input/Output（通用输入输出），MCU 最基础、用得最多的外设，没有之一。EC 那颗 8051 管键盘扫描、风扇 PWM、电池 SMBus、开机键检测，全是 GPIO 的活。next: [[EC_eSPI]]
🎯 一句话定位 

GPIO = MCU 芯片上那些可以软件配置成"输入"或"输出"的引脚。输入时读外部电平（0/1），输出时写外部电平（0/1），还能配置上拉/下拉、中断触发等属性。

[[EC]] 的 GPIO 就是EC 跟主板其他芯片"握手"的物理触点——比如拉 
"PS_ON#" 低电平让 ATX 开机、读键盘矩阵行列线、读温度传感器的 [[ADC]] 值（通过 GPIO 复用成 ADC 脚）。

⚙️ GPIO 内部长啥样（简化框图）

                    VDD (3.3V/1.8V)
                      │
                   [上拉电阻] (可配置开关)
                      │
    输出寄存器 ──→ 推挽/开漏输出驱动器 ──→ 引脚 (Pad)
                      │
    输入寄存器 ←── 施密特触发器 / 采样 ──→ 引脚
                      │
                   [下拉电阻] (可配置开关)
                      │
                     GND

每个 GPIO 引脚背后有一组寄存器（在 MCU 的内存映射地址空间里），软件通过读写这些寄存器来控制引脚行为：

- 方向寄存器 (DIR / MODER)：配置该引脚是输入还是输出
- 输出寄存器 (ODR / DOUT)：输出模式下，写 1 引脚高电平，写 0 引脚低电平
- 输入寄存器 (IDR / DIN)：输入模式下，读到的就是引脚当前电平（0/1）
- 上拉/下拉配置 (PUPDR)：内部上拉电阻（弱拉到 VDD）或下拉电阻（弱拉到 GND），防止悬空
- 复用功能 (AFR / ALTFUNC)：有些 GPIO 引脚可以切换到第二功能（如 UART TX、I2C SCL、PWM 输出），这时 GPIO 模块断开，由对应外设接管

🔌 EC 里的 GPIO 典型用法

EC 那颗 8051 的 GPIO 分布在几十到一百多个引脚上，典型分配：

功能 GPIO 方向 说明
PS_ON# 输出（开漏） EC 拉低此脚 → ATX 电源出主电
SUSB# / SUSC# 输出 控制 S3/S5 睡眠状态
键盘矩阵行/列 输入/输出 扫描键盘，行列交叉点检测
风扇 PWM 输出（复用 Timer） 输出占空比信号控制风扇转速
温度 NTC 输入 输入（复用 ADC） 读热敏电阻电压，换算温度
电池 SMBus 输入/输出（复用 I2C） 跟电池管理芯片通信
开盖检测 输入 笔记本盖子霍尔传感器
Fn 键 输入（中断触发） EC 截获 Fn 组合键，发 SCI 给 PCH

📊 GPIO 的几个关键参数（选型/调试时碰）

参数 典型值 说明
电平域 3.3V / 1.8V / 5V-tolerance 跟 MCU 供电域走，但有些引脚能耐受 5V 输入
驱动能力 2mA ~ 20mA 直接点 LED 够用，驱动继电器/电机要加三极管
上拉电阻 10kΩ ~ 100kΩ（内部） 可配置，外部也可以外加
输入阈值 TTL / CMOS / Schmitt CMOS 阈值是 VDD/2，Schmitt 有滞回防抖动
中断触发 上升沿/下降沿/高/低电平 输入变化时能唤醒 CPU，不用轮询

🔗 回链你这条线

- EC 的 GPIO 拉 PS_ON# → ATX 电源出电 → VRM 出 Vcore → 你前面那整条链的第一步
- EC 的 GPIO 读键盘矩阵 → 你按 Fn+F2 调亮度 → EC 截获 → 发 SCI 给 PCH → ACPI 驱动处理 → 
"/sys/class/backlight/" 变化
- EC 的 GPIO 复用 ADC 读温度 → 风扇 PWM 调速 → 你笔记本散热策略的根
- GPIO 的"上拉/下拉" 跟上一轮反相器 CMOS 结构里的 PMOS/NMOS 上拉下拉是同一套思想——只是 GPIO 的上拉电阻弱很多（kΩ 级），不是推挽驱动

🛠 容易混的点

- GPIO 不是"万能引脚"：每个 GPIO 的复用功能是固定的（比如 PA9 只能是 USART1_TX 或 TIM1_CH2），不是软件随便映射的，要看 datasheet 的引脚功能表
- 开漏输出 vs 推挽输出：推挽 = 输出 1 时 PMOS 拉高、输出 0 时 NMOS 拉低；开漏 = 输出 0 时 NMOS 拉低、输出 1 时高阻（要靠外部上拉电阻拉高）。I2C 总线必须用开漏，多个设备共线才不会打架
- GPIO 中断不是"并行"的：虽然多个 GPIO 都能触发中断，但 MCU 的中断控制器（NVIC）同一时间只能处理一个中断服务函数，优先级高的先跑
