透视投影公式的核心目的只有一个：把三维空间的点，压到二维屏幕上，同时产生“近大远小”的效果。

它的数学本质是相似三角形，非常简单，然后才包装成矩阵形式。
#核心原理：相似三角形

假设摄像机在原点，看向 -Z 方向（[[OpenGL]] 惯例），成像平面在 
"z = -n"（近平面）：

                  物体 (x, y, z)
                       |
                       |  (视线连线)
                       |
成像平面 (z=-n) --------●--------> 屏幕上的点 (x', y')
                       |
                       |
                  摄像机 (0,0,0)

根据相似三角形：

x' / n = x / (-z)    →  x' = (n * x) / (-z)
y' / n = y / (-z)    →  y' = (n * y) / (-z)

关键发现：
"x'" 和 
"y'" 都要除以 -z（深度）。这就是“近大远小”的来源——远处的物体（z 很大），除以一个大数，成像变小；近处的物体，除以一个小数，成像变大。

二、写成 4x4 矩阵

为了把除法操作放进线性变换里，引入了齐次坐标（加一个 w 分量）。透视投影矩阵 
"P" 长这样（OpenGL 惯用形式）：

P = 
[  n/r    0      0           0     ]
[   0    n/t     0           0     ]
[   0    0   -(f+n)/(f-n)  -2fn/(f-n)]
[   0    0      -1           0     ]

其中：

- 
"n" = 近平面距离（near）
- 
"f" = 远平面距离（far）
- 
"r" = 近平面的右边界（right = n * tan(fov/2)）
- 
"t" = 近平面的上边界（top = n * tan(fov/2) / aspect）

三、矩阵乘完发生了什么

把一个观察空间的点 
"(x, y, z, 1)" 乘以 
"P"：

[x']   [  n/r    0      0           0     ] [x]
[y'] = [   0    n/t     0           0     ] [y]
[z']   [   0    0   -(f+n)/(f-n)  -2fn/(f-n)] [z]
[w']   [   0    0      -1           0     ] [1]

得到：

x' = (n/r) * x
y' = (n/t) * y
z' = -(f+n)/(f-n) * z - 2fn/(f-n)
w' = -z

注意 
"w' = -z" —— 深度信息被编码到了 w 分量里。

四、透视除法（真正产生“近大远小”的一步）

顶点着色器输出 
"gl_Position = (x', y', z', w')" 后，GPU 自动做：

screen_x = x' / w' = (n/r * x) / (-z)    ← 除以了 -z
screen_y = y' / w' = (n/t * y) / (-z)    ← 除以了 -z
ndc_z    = z' / w'

看到了吗？x' 和 y' 都除以了 -z——这就是最开始那个相似三角形的除法。所以“近大远小”不是矩阵乘法产生的，而是透视除法这一步干的。

五、为什么说“世界绕着摄像机动”

因为透视投影公式要求摄像机在原点、看向 -Z 方向。如果你的摄像机不在原点，就得先用 
"V" 矩阵（视图矩阵）把全世界顶点搬过来，让摄像机假装在原点。

所以整个链条是：

模型空间 → [M] → 世界空间 → [V] → 观察空间（摄像机在原点）→ [P] → 裁剪空间 → [÷w] → NDC → 屏幕
                              ↑                         ↑
                        “世界绕摄像机动”           “透视公式要求摄像机在原点”

透视投影公式本身没要求“世界动”，但它要求“摄像机在原点”——这个要求迫使前面的 V 矩阵去做“世界反向动”这件事。

六、一个直观的数字例子

一个点在 
"(0, 1, -5)"（摄像机前方 5 单位），近平面 n=1，fov=90°，aspect=16/9：

t = 1 * tan(45°) = 1
r = 1 * tan(45°) / (16/9) ≈ 0.5625

x' = (1/0.5625) * 0 = 0
y' = (1/1) * 1 = 1
z' = ...（略）
w' = -(-5) = 5

screen_x = 0 / 5 = 0    （居中）
screen_y = 1 / 5 = 0.2  （离中心 0.2 个单位）

如果这个点移到 
"(0, 1, -10)"（更远一倍）：

w' = 10
screen_y = 1 / 10 = 0.1  （离中心 0.1，更小了）

远一倍，成像高度减半——这就是透视投影的数学本质。
