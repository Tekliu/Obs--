[[透视投影公式]]
1. 模型空间（Model Space / Object Space / 局部空间）
- 每个物体自己坐标系的原点，比如一个立方体的中心或角落 
- 建模软件里导出时就是这套坐标
- 比如立方体 8 个顶点：(±1, ±1, ±1) 
2. 世界空间（World Space）
- 所有物体共用的坐标系，场景的"绝对坐标"
- 模型矩阵 "M" 干的事：把物体从"自己家里"搬到"世界地图的某个位置"，包含平移 + 旋转 + 缩放 - 比如把立方体放到世界坐标 (10, 0, 0) 处
3. 观察空间 / 摄像机空间（View Space / Camera Space）
- 以摄像机为原点的新坐标系，摄像机看向 -Z（右手系）或 +Z（左手系，DX/Unity）
- 视图矩阵 "V" 干的事：把整个世界"反向搬"，让摄像机落在原点、朝向标准方向 
- 直觉：不是摄像机动，是整个世界反过来动，让摄像机"觉得自己在原点" 
4. 裁剪空间（Clip Space / 齐次空间）——
- 投影矩阵 "P"（透视 / 正交）干的事：把观察空间压成一个棱锥台（透视）→ 立方体（正交/透视后经除法）的过渡态 
- 此时坐标还是 齐次坐标 (x, y, z, w)，w 里藏着深度信息
- 这一步还要做视椎体裁剪（超出摄像机能看到范围的三角形直接砍掉）→ 所以叫"裁剪空间"
5. NDC（Normalized Device Coordinates，标准化设备坐标） 
- 对裁剪空间做透视除法： "(x, y, z, w) → (x/w, y/w, z/w)" 
- 结果范围：x, y, z ∈ [-1, 1]（OpenGL）或 z∈[0,1]（DX/ Vulkan/ Metal）
- 到这步已经跟具体摄像机参数无关了，是"归一化"后的结果 6. 屏幕空间（Screen Space） - Viewport（视口）变换：把 NDC 的 [-1,1]×[-1,1] 映射到窗口像素，比如 1920×1080 
- 公式大致： "screen_x = (ndc_x + 1) × width/2 + offset_x" - z 值保留做深度测试（Z-buffer），决定哪个片元靠前
