段寄存器"这名就是这来的——内存按"段"切，CS 管代码段、DS 管数据段、SS 管栈段、ES/FS/GS 管额外数据段。实模式下你学 8086 汇编天天跟这四个（CS/DS/SS/ES）打交道
保护模式（32/64 位现代 OS）下 CS 不存段基址了
- 实模式：CS = 段基址（×16 用）
- 保护模式：CS = 选择子（Selector），指向 [[GDT and LDT]] 里的一项段描述符，描述符里才存基址/限长/权限
- 所以 
"CS:IP" 在现代体系里是 "选择子:偏移"，物理地址要 GDT[CS]基址 + IP 才算出来（再加上分页 CR3 那层，就是虚拟地址→物理地址的完整路径）

一句糙的：实模式 CS 是段号，保护模式 CS 是 GDT 下标。
