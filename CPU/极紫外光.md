极紫外光，英文名 EUV（Extreme Ultraviolet），是电磁波谱里一段特别"难伺候"的光——夹在普通紫外线和 X 射线之间，波长大约 10–120 nm，光刻机里用的是 13.5 nm 这一小段。

**电磁波谱里的位置**

波段 波长
可见光 400–700 nm
深紫外 DUV（ArF 浸没） 193 nm
极紫外 EUV 10–120 nm（光刻取 13.5）
软 X 射线 <10 nm

可以看到，EUV 已经快摸到 X 射线的边了，光子能量 ~92 eV，比可见光大几十倍。

为什么叫"极"紫外？因为它**极难用**

普通紫外光还能用透镜、还能在空气中传一点；EUV 是"三无"选手——
- 空气都吸它：**氧气、水蒸气对 13.5 nm 吸收极强**，光刻机整机必须 **抽真空，晶圆在真空中跑**
- 玻璃透不过：普通透镜直接废掉，连氟化钙（CaF₂）这种 DUV 用的材料都对 EUV 强吸收，所以 EUV 光刻机全程用反射镜，**不能有用透镜的折射系统**
- 几乎所有材料都吸：连**镜子本身都只能靠 Mo/Si 多层膜**（几十层交替镀，单镜反射率才 ~70%），而且每多一面镜能量就折一层

光刻为啥非得用 EUV

芯片光刻的本质公式：[[分辨率]] ∝ λ / NA（波长越小、数值孔径越大，能刻的线越细）。

- DUV 浸没式做到 193 nm，靠多重曝光 + 各种 tricks 勉强推到 7 nm，再往下多重曝光成本爆炸、良率崩
- 换成 13.5 nm EUV，波长直接砍到 1/14，单次曝光就能刻 7/5/3/2 nm 的精细层——这就是 ASML 那台 NXE 值几亿美元的根本原因

一句收口

EUV = 波长 10–120 nm 的一段"紫外线里的极端段"，因为太容易被吸收所以难产生、难传导、难收集，但也正因为波长短，它是人类目前量产级能拿到的最细光刻光源——再往下就得上 X 射线（但 X 射线连反射镜都难搞，目前没量产路数）。

所以你看，从籽晶（硅）→ EUV 光源（13.5 nm 光）→ EUV 光刻（全反射+真空）→ 3 nm 芯片，整条链就是"越做越细、越做越难"。🤏
